Entrega

Configure os parâmetros de frete e os bairros atendidos.

Parâmetros de cálculo do frete

Frete = taxa do entregador + (distância × 2 × preço da gasolina ÷ consumo por litro). Atualize o preço da gasolina sempre que ele mudar.

Esse valor é o que vai integralmente para o entregador em cada corrida — é descontado do frete cobrado do cliente para calcular quanto sobra de fato pra casa (veja em Receita → Detalhamento da entrega).

Distância real via Google Maps opcional

Por padrão, o frete usa a distância aproximada cadastrada em cada bairro (abaixo). Se você configurar uma chave de API do Google Maps aqui, o sistema calcula a distância real de condução até o endereço completo do cliente (rua e número) no momento do pedido — muito mais preciso, principalmente em bairros grandes. Se a chave não estiver configurada, ou se a consulta falhar por qualquer motivo, o site volta sozinho a usar a distância estimada do bairro — o checkout nunca trava por causa disso.

Como conseguir essa chave (passo a passo)
  1. Acesse o Google Cloud Console e crie um projeto (ou use um existente).
  2. Em "APIs e serviços", ative a Distance Matrix API e a Maps JavaScript API.
  3. É necessário ativar o faturamento (cartão de crédito) no projeto do Google Cloud — o Google dá uma cota gratuita mensal, mas exige cartão cadastrado mesmo para usá-la.
  4. Em "Credenciais", crie uma chave de API.
  5. Importante: restrinja a chave por "referenciador HTTP" (HTTP referrer) com o domínio do seu site, pra ninguém mais conseguir usá-la.
  6. Copie a chave gerada e cole no campo acima.

Dados da loja

Essas informações aparecem no site (cabeçalho, rodapé, página de contato).

Pra achar esse link: procure sua loja pelo nome no Google Maps, clique em "Compartilhar" no local verificado e copie o link. Isso mostra o nome da loja no pino (não só uma coordenada solta). Se deixar em branco, o site usa a latitude/longitude abaixo.

Pra achar a latitude/longitude certas: abra o endereço no Google Maps, clique com o botão direito bem em cima do local exato → os números que aparecem no topo do menu são a latitude e a longitude (nessa ordem) — é só copiar e colar aqui.
