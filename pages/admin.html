Dados da loja

Essas informações aparecem no site (cabeçalho, rodapé, página de contato).

Pra achar esse link: procure sua loja pelo nome no Google Maps, clique em "Compartilhar" no local verificado e copie o link. Isso mostra o nome da loja no pino (não só uma coordenada solta). Se deixar em branco, o site usa a latitude/longitude abaixo.

Pra achar a latitude/longitude certas: abra o endereço no Google Maps, clique com o botão direito bem em cima do local exato → os números que aparecem no topo do menu são a latitude e a longitude (nessa ordem) — é só copiar e colar aqui.

Backup dos dados

Como este site não usa um servidor central, os dados ficam salvos apenas neste navegador. Exporte um backup regularmente e, se precisar usar outro aparelho, importe o mesmo arquivo lá.

Restaurar de fábrica

Apaga cardápio, bairros, pedidos, clientes e configurações salvos neste navegador e recarrega os valores originais do site (endereço, horários, cardápio padrão etc.). Use isso se o site parecer "travado" numa versão antiga depois de uma atualização de arquivos. Essa ação não pode ser desfeita — exporte um backup antes, se quiser guardar os dados atuais.
